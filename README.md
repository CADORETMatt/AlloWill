# Allowill

## Description
Allowill est une application interactive qui combine des éléments de jeu et d'édition multimédia. Elle propose une expérience immersive avec des fonctionnalités variées pour les utilisateurs.

## Fonctionnalités
- **Jeu interactif** : Une expérience de jeu captivante avec des éléments de gestion de tâches et de navigation.
- **Éditeur de sons et musiques (Beta)** : Une page dédiée à l'édition et à la création de sons et musiques, avec des options avancées telles que le crossfade, le granular, et le panoramique.
- **Visualisation graphique** : Intégration d'un canvas pour des rendus visuels interactifs.

## Installation
1. Clonez ce dépôt avec la commande :  
   ```bash
   git clone <url-du-dépôt>
   ```
2. Installez les dépendances :  
   ```bash
   npm install
   ```
3. Lancez le projet :  
   ```bash
   npm start
   ```
